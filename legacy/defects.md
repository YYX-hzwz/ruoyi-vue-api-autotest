
# RuoYi-Vue 项目缺陷记录

## 1. 验证码开关配置不生效
- **模块**：登录认证
- **严重程度**：中
- **现象**：在 `application.yml` 或 `application-druid.yml` 中设置 `captchaEnabled: false` 后，登录接口仍提示“验证码已失效”
- **根因**：验证码开关由数据库 `sys_config` 表控制，配置文件未覆盖
- **影响**：自动化测试无法登录，需修改数据库或代码
- **解决方式**：已通过注释 `SysLoginService` 中 `validateCaptcha` 调用绕过

## 2. 用户创建接口未校验密码长度
- **模块**：用户管理
- **严重程度**：低
- **现象**：创建用户时密码设置为 `123`（少于最小长度），接口仍返回成功（HTTP 200）
- **影响**：弱密码用户可被创建，安全风险
- **建议**：后端增加密码长度校验

## 3. 普通角色用户可访问用户列表
- **模块**：权限控制
- **严重程度**：高
- **现象**：分配普通角色（role_id=2）的用户登录后，调用 `/system/user/list` 返回 200 和数据，应无权限
- **影响**：越权查看用户数据，违反权限设计
- **建议**：检查菜单权限配置或后端接口权限注解

## 4. 角色创建接口对状态字段校验不一致
- **模块**：角色管理
- **严重程度**：低
- **现象**：使用 `status=9` 创建角色未报错，但 `status=1` 时部分场景返回 500
- **影响**：非法状态值未被统一拦截
- **建议**：后端添加枚举校验
