# 缺陷记录

## 缺陷1：普通角色越权访问用户列表
- **模块**：权限控制
- **严重程度**：高
- **现象**：分配普通角色（role_id=2）的用户登录后，调用 `/system/user/list` 返回 200 和数据，应无权限。
- **根因**：后端接口缺少权限注解或配置错误。
- **建议**：检查菜单权限配置，添加 `@PreAuthorize` 注解。

## 缺陷2：验证码开关配置不生效
- **模块**：登录认证
- **严重程度**：中
- **现象**：在 yml 中设置 `captchaEnabled: false` 后仍提示“验证码已失效”。
- **根因**：验证码开关由数据库 `sys_config` 表控制。
- **解决方式**：临时注释登录服务中的验证码校验代码。

## 缺陷3：用户创建接口未校验密码长度
- **模块**：用户管理
- **严重程度**：低
- **现象**：密码设置为 `123` 仍创建成功。
- **建议**：后端增加密码长度校验。

## 缺陷4：角色状态字段校验不一致
- **模块**：角色管理
- **严重程度**：低
- **现象**：`status=9` 未报错，`status=1` 部分场景返回 500。
- **建议**：添加枚举校验。
